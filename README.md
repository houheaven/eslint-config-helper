
# @houheaven/eslint-config-helper

> Eslint 规则助手，基于 Eslint Flat Config 的规则集。  
> 主要功能是处理 Javascript、Typescript、Vue、HTML 中的语法校验、代码格式化。  

## 版本
本仓库采用 pnpm workspace 维护两个版本：

- v2（Legacy Config）：适配 Eslint v8，[查看文档](./packages/v2-legacy/README.md)
- v3（Flat Config）：适配 Eslint v9+，[查看文档](./packages/v3-flat/README.md)
