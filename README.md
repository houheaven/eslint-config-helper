# @houheaven/eslint-config-helper

A collection of ESLint configurations and helpers.

## Packages

- **@houheaven/eslint-config-helper-core**: Core rules and utilities.
- **@houheaven/eslint-config-helper-legacy**: Legacy ESLint configuration (eslintrc).
- **@houheaven/eslint-config-helper-flat**: Modern ESLint Flat Config helper.

## Installation

```bash
pnpm install
```

## Development

This is a monorepo managed by pnpm workspaces.

- `packages/core`: Core logic and rule definitions.
- `packages/legacy`: Legacy configuration implementation.
- `packages/flat`: Flat Config implementation.
- `demo`: Demo projects for testing configurations.
