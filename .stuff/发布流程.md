
# 发布流程

## 切换镜像
如果镜像用的是淘宝，先切换至官方镜像，否则直接跳过此步。
```
npm config list
npm config set registry https://registry.npmjs.org
```

## 登录账号
若已登录，跳过此步。
```
npm login
```

## 检查 package.json
修改版本号 version 。

## 测试版本
检查有没有异常文件混入。
```
npm pack
```

## 发布版本
```
npm publish
```

## 切换为淘宝镜像
```
npm config list
npm config set registry https://registry.npmmirror.com
```
