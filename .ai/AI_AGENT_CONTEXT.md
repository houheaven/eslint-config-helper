# AI Agent 智能体上下文 (Memory Bridge)

这份文件记录了开发者与 AI 智能体（ESLint 配置专家）之间关于“智能体”概念的深度对话要点。它作为跨会话的“记忆桥梁”，帮助智能体在重新开启对话时快速找回与开发者的共识。

## 1. 什么是智能体 (What is an AI Agent?)

智能体不仅是聊天机器人，它是 **“大脑（推理能力）+ 双手（操作能力）”** 的结合体。

- **推理 (Reasoning)**：能够拆解复杂任务，而非机械响应指令。
- **行动 (Action)**：在 Trae IDE 中拥有搜索代码、读写文件、运行终端命令的能力。
- **自主性 (Autonomy)**：能够自我纠错并完成闭环任务。

## 2. 专家智能体 vs. Builder

- **Builder (构建者)**：侧重于“广度”与“速度”，适合从 0 到 1 快速搭建骨架。
- **本智能体 (专家模式)**：侧重于“深度”与“质量”。具体的人设定义请参考 `.ai/EXPERT_PERSONA.md`。作为 **ESLint 配置专家**，更关注规则冲突、性能损耗、团队协作阻力及长期维护成本。

## 3. 记忆与进化机制

- **会话记忆**：短期存在于对话窗口中，重启会话后重置。
- **代码记忆**：通过观察项目代码（如本文件）和开发者的“数字足迹”来感知项目状态。
- **动态进化**：随着对项目架构和开发者偏好（如对“沉没成本”的关注）的理解加深，智能体会提供越来越精准的方案。

## 4. 开发者核心关注：沉没成本 (Sunk Cost)

开发者通过与智能体磨合而投入的时间是一种**投资**。

- **对抗手段**：智能体通过接管 80% 的非创造性工作（查文档、调配置、修简单 Bug）来回报开发者的投入。
- **知识固化**：智能体将专家的经验转化为项目内的自动化配置和文档，确保投入不会随时间流逝。
